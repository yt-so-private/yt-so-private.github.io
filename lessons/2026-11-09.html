Cutting it close

ギリギリになったときの英語。

0. 今日の流れ

  • 2分まず聞く
  • 3分チャンク
  • 3分音読
  • 2分軽いシャドーイング
  • 4分瞬間英作文
  • 3分クイズ

1. まず聞く

一度通して聞く。日本語はあとでOK。

I'm running behind this morning, and I'm stuck in traffic.

I'm worried I won't make it in time for my first appointment.

Last time I cut it close, too. If I had left earlier, I wouldn't have been so stressed.

I'll send a quick heads-up and hope for the best.

今朝は遅れていて、渋滞にはまっている。最初の約束に間に合わないかもしれない。前回もギリギリだった。もっと早く出ていたら、こんなに焦らなかったのに。ひとこと連絡を入れて、うまくいくことを祈ろう。

2. 意味とチャンク

I'm stuck in traffic 新規
渋滞にはまっている
I'm running behind 新規
予定より遅れている
make it in time 新規
間に合う
cut it close 新規
ギリギリになる
heads-up 復習
事前のちょっとした連絡（復習）

文法メモ：If I had left earlier, I wouldn't have been so stressed.（過去の仮定：If + 過去完了, would not have + 過去分詞 ＝ もし〜していたら…しなかったのに。実際は早く出なかった、という後悔や反省を表す。）

3. 音読

2–3回、声に出して読む。

I'm stuck in traffic.

I'm running behind this morning.

I hope I can make it in time.

I cut it close again.

4. 軽いシャドーイング

▶で聞いて、少し遅れて真似する。

Sorry, I'm running behind.

We should make it in time.

If I had left earlier, I'd have made it.

5. 瞬間英作文

日本語を見て、英語を口に出してから「英語を見る」。

渋滞にはまってる。

I'm stuck in traffic.

ちょっと遅れてるんだ。

I'm running behind.

たぶん間に合うよ。

I think we'll make it in time.

もっと早く出ていたらよかった。

If I had left earlier, it would have been easier.
