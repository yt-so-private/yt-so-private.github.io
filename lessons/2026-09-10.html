英語の10分一覧へ
Daily English · B1

I ran into an old friend

偶然の再会 · ~15–18分 · 新規フレーズ中心

0. 今日の流れ

  • 2分まず聞く（意味は後で）
  • 3分チャンクで意味をつかむ
  • 3分音読（2–3回）
  • 2分軽いシャドーイング
  • 3分瞬間英作文
  • 3分クイズ

1. まず聞く

一度通して聞く。日本語はあとでOK。

I was about to leave the café when I ran into an old friend.

We had lost touch for a while, so we sat down to catch up.

It almost slipped my mind that I had somewhere else to be.

日本語を見る
カフェを出ようとしたところで、昔の友だちにばったり会った。しばらく疎遠だったので、座って近況を話した。ほかに用事があったことを、危うく忘れそうになった。

2. 意味とチャンク

run into 新規
（人に）ばったり会う・偶然出会う。
lose touch 新規
疎遠になる（連絡が途絶える）。
catch up 新規
（人と）近況を話し合う。catch up on（遅れを取り戻す）とは別。
for a while 新規
しばらくの間。
I was about to … 新規
まさに〜するところだった（直前の予定・動作）。
slip my mind 復習
うっかり忘れる（頭からすっぽり抜ける）。

3. 音読

▶で聞いてから、声に出して2–3回。

I was about to leave the café when I ran into an old friend.

We had lost touch for a while, so we sat down to catch up.

It almost slipped my mind that I had somewhere else to be.

4. 軽いシャドーイング

▶で聞いて、少し遅れて真似する（完璧じゃなくてOK）。

I was about to leave the café when I ran into an old friend.

We had lost touch for a while, so we sat down to catch up.

It almost slipped my mind that I had somewhere else to be.

5. 瞬間英作文

日本語を見て、英語を口に出してから「英語を見る」。
