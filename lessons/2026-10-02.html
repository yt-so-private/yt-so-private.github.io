英語の10分一覧へ
Daily English · B1

I'll run with it

それでいくよ · ~15–18分 · 新規フレーズ中心

0. 今日の流れ

  • 2分まず聞く（意味は後で）
  • 3分チャンクで意味をつかむ
  • 3分音読（2–3回）
  • 2分軽いシャドーイング
  • 3分瞬間英作文
  • 3分クイズ

1. まず聞く

一度通して聞く。日本語はあとでOK。

I'll run with it.

That tracks.

Let's park that.

I'm open to it.

Given that it's raining, I'll stay in.

That works for me.

日本語を見る
それでいくよ。筋が通ってるね。それはいったん置いとこう。それに前向きだよ。雨なので、家にいるよ。それで大丈夫。

2. 意味とチャンク

I'll run with it 新規
それでいく・それを採用して進める。
That tracks 新規
筋が通る・なるほど（話がつながる感じ）。
Let's park that 新規
それはいったん置いとこう（あとで戻る前提の棚上げ）。
I'm open to it 新規
それに前向き・検討していいよ。
Given that … 新規
〜を考えると／〜なので。Given that it's raining, I'll stay in.
that works for me 復習
それで大丈夫・私はそれでOK。

3. 音読

▶で聞いてから、声に出して2–3回。

I'll run with it.

That tracks.

Let's park that.

I'm open to it.

Given that it's raining, I'll stay in.

4. 軽いシャドーイング

▶で聞いて、少し遅れて真似する（完璧じゃなくてOK）。

I'll run with it.

That tracks.

I'm open to it.

Given that it's raining, I'll stay in.
