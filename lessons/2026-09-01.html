英語の10分一覧へ
Daily English · 15–18 min

A quick stop nearby

近くのお店に少し寄る日の、短く自然な英語。

0. 今日の流れ

  • ~2分1. まず聞く
  • ~3分2. 意味とチャンク
  • ~3分3. 音読（声に出して2–3回）
  • ~3分4. 軽いシャドーイング
  • ~3分5. 瞬間英作文
  • ~3分6. クイズ

1. まず聞く

意味はまだ見ない。音と流れだけ。

I don't want to run out of tea, so I'll drop by a small shop around the corner.

I can pick some up while I'm there. I'll take a reusable bag, just in case I get one more thing.

The stop should be quick, and then I'll head home.

日本語を見る
お茶を切らしたくないので、すぐ近くの小さなお店にちょっと寄ります。そこにいるついでに買っておけます。もう一つ何か買う場合に備えて、再利用できる袋を持っていきます。寄り道はすぐ済むはずで、その後は家に帰ります。

2. 意味とチャンク

drop by 復習
ちょっと寄る。短い訪問のイメージ。
run out of 復習
〜を切らす、〜がなくなる。run out of + 物。
around the corner 復習
角を曲がったところ、すぐ近く。
pick something up 復習
何かを買って帰る・受け取る。代名詞は pick it up の語順。
just in case 復習
念のため。起こるかもしれないことへの小さな準備。
while I am there 新規
そこにいるついでに。会話で用事を追加するときに便利。

3. 音読

▶で聞いてから、声に出して2–3回。

I don't want to run out of tea, so I'll drop by a small shop around the corner.

I can pick some up while I'm there.

I'll take a reusable bag, just in case I get one more thing.

The stop should be quick, and then I'll head home.

4. 軽いシャドーイング

▶で聞いて、少し遅れて真似する（完璧じゃなくてOK）。

I don't want to run out of tea, so I'll drop by a small shop around the corner.

I can pick some up while I'm there.

I'll take a reusable bag, just in case I get one more thing.

The stop should be quick, and then I'll head home.

5. 瞬間英作文

日本語を見て、英語を口に出してから「英語を見る」。

お茶を切らしたくありません。

英語を見る
I don't want to run out of tea.

すぐ近くのお店にちょっと寄ります。

英語を見る
I'll drop by a shop around the corner.

そこにいるついでに、それを買っておけます。

英語を見る
I can pick it up while I'm there.
