Daily English · B1

On a whim

平日のお休みに、思いつきでふらっと出かける日の英語。

0. 今日の流れ

  • 2分まず聞く
  • 3分チャンク
  • 3分音読
  • 2分軽いシャドーイング
  • 4分瞬間英作文
  • 3分クイズ

1. まず聞く

一度通して聞く。日本語はあとでOK。

It was a day off in the middle of the week, so I decided to get out and about. On a whim, I hopped on a train to a small town I'd never visited.

On the way, a friend texted me: "Mind if I come along?" I wrote back, "Sure, the more the merrier!"

We had an hour to kill before lunch, so we walked along the river. Then it started to drizzle. But we were already halfway there, so there was no point in going back for an umbrella.

We found a tiny café, had a long lunch, and laughed a lot. Honestly, if every day off felt like this, I'm all for it.

週の真ん中のお休みだったので、外に出かけることにした。思いつきで、行ったことのない小さな町行きの電車に飛び乗った。途中で友だちから「一緒に行ってもいい？」とメッセージ。「もちろん、人数は多いほうが楽しいよ！」と返した。お昼まで1時間あったので、川沿いを歩いた。すると小雨が降ってきた。でももう半分来ていたから、傘を取りに戻っても意味がなかった。小さなカフェを見つけて、のんびりランチして、たくさん笑った。正直、休みの日がいつもこんなふうなら大賛成だ。

2. 意味とチャンク

on a whim 新規
思いつきで・気まぐれで
get out and about 新規
外に出かける・あちこち出歩く
the more the merrier 新規
人数が多いほど楽しい（大歓迎だよ）
I'm all for it 新規
大賛成だよ・それいいね
kill time 復習
時間をつぶす（復習）

文法メモ：There was no point in going back for an umbrella.（There's no point in ＋ -ing ＝ 〜しても意味がない・ムダだ。in のあとは動詞の -ing。会話では There's no point worrying about it. と in を省くことも多い。）

3. 音読

2–3回、声に出して読む。

On a whim, I hopped on a train.

Sure, the more the merrier!

There was no point in going back for an umbrella.

If every day off felt like this, I'm all for it.

4. 軽いシャドーイング

▶で聞いて、少し遅れて真似する。

Let's get out and about.

The more the merrier!

There's no point in worrying.

I'm all for it.

5. 瞬間英作文

日本語を見て、英語を口に出してから「英語を見る」。

思いつきで髪を切ったんだ。

I got a haircut on a whim.

天気がいいし、外に出かけよう。

The weather's nice, so let's get out and about.

友だちも連れてきていい？—もちろん、多いほど楽しいよ！

Can I bring a friend? — Sure, the more the merrier!

今さら心配しても意味ないよ。

There's no point in worrying about it now.

早めに出るの？大賛成だよ。

Leaving early? I'm all for it.
