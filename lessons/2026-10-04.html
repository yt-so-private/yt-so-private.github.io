Daily English · B1

That settles it

それで決まり · ~15–18分 · 新規フレーズ中心

0. 今日の流れ

  • 2分まず聞く（意味は後で）
  • 3分チャンクで意味をつかむ
  • 3分音読（2–3回）
  • 2分軽いシャドーイング
  • 3分瞬間英作文
  • 3分クイズ

1. まず聞く

一度通して聞く。日本語はあとでOK。

That settles it.

I'll hold off.

Point taken.

Let's leave it open.

Now that we've talked it through, that settles it.

Call it a day.

日本語を見る
それで決まり。しばらく控えるよ。なるほど、分かった。まだ決めないでおこう。話し合った今なら、それで決まりだ。今日はここまでにしよう。

2. 意味とチャンク

That settles it 新規
それで決まり（議論や選択の締め）。
I'll hold off 新規
しばらく控える・見合わせる。
Point taken 新規
なるほど・指摘は分かる（相手の意見を受け止める）。
Let's leave it open 新規
まだ決めないでおく・余白を残す。
Now that … 新規
〜した今 / 〜なので（いまは）。Now that we've talked it through, that settles it.
Call it a day 復習
今日はここまで・ひと区切りつける。

3. 音読

▶で聞いてから、声に出して2–3回。

That settles it.

I'll hold off.

Point taken.

Let's leave it open.

Now that we've talked it through, that settles it.

4. 軽いシャドーイング

▶で聞いて、少し遅れて真似する（完璧じゃなくてOK）。

That settles it.

I'll hold off.

Point taken.

Now that we've talked it through, that settles it.

5. 瞬間英作文
